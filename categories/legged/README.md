## Comparison

None of the four entries in this first batch is a classic quadruped; all are bipeds or wheeled-leg machines, recategorized from the source site's mixed 'biped' bucket. Open Duck Mini is a desktop-scale (~42 cm) biped whose official hub repository states a full BOM under USD 400 and uses Feetech STS3215 servos under Apache-2.0. Unitree Qmini is a 3D-printable biped with 11 Unitree 8010 motors and a Raspberry Pi 4B reference computer; the official repo is CC BY-NC-SA 4.0, and a total BOM price was not found. AlexbotMini is a Fourier-sponsored 1.2 m-class biped (source and README: 700 mm lower body + 500 mm upper body) whose hardware repo is BSD-3-Clause; a public BOM total was not confirmed. The Micro Wheeled-leg Robot is a desktop two-wheeled-leg design with an ESP32 controller, Feetech bus servos in the legs, and FOC wheel motors; no LICENSE file was found in the repository.
