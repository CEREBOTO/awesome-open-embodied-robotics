## Comparison

This first batch covers three very different layers of the arm stack. SO-101 is a low-cost, 3D-printed follower/leader arm built around Feetech STS3215 bus servos and the LeRobot software stack. SO-ARM 102, maintained by Robonine, is a successor to SO-ARM 100 and SO-101 in that same low-cost leader–follower layer, built to work with LeRobot. Each arm has five degrees of freedom plus a parallel gripper (85 mm span), a rated payload of 300 g, and a horizontal reach of 483 mm (473 mm behind the base). The official DIY budget is about USD 342 for components, or about USD 388 including printing material. Hardware designs are CERN-OHL-P-2.0 and software is Apache-2.0. The GitHub license API reports the repository as CC-BY-4.0, which is the documentation license. OpenArm is a human-scale 7-DoF-per-arm quasi-direct-drive platform with a CAN-FD control bus, a stated complete bimanual system price on the order of USD 6,500, and a clearly split license (CERN-OHL-S-2.0 hardware, Apache-2.0 software). DexWrist is a 2-DoF research wrist intended as a drop-in pitch–yaw upgrade, but as of the source-check date we could not find a public CAD or firmware repository, so its open-source status is unconfirmed.
