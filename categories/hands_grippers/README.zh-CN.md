## 对比分析

这是第一批里条目最多的一类。低成本 3D 打印腱传动或刚软混合手（LEAP Hand v2 官方零件页现写明因关税零件成本约 300 美元，同页仍保留 2025 年 8 月飞特 221.95 美元 + 其他 251.53 美元的分项；以及 Robot Nano Hand、DexHand）与基于 Dynamixel 的研究用手（LEAP Hand v1、RUKA、ORCA、LEAP Hand v2 Advanced）并列。许可证并不统一：LEAP Hand v1 的 CAD 申请页写明设计为 CC BY-SA 4.0（可商业使用，需署名并相同方式共享），而 v1 API 为 CC BY-NC 4.0，LEAP Hand v2 的 CAD 为 CC BY-NC-SA。ORCA 硬件为允许商业使用的 CC BY 4.0（需署名），RUKA 仓库为 MIT。eFlesh 和 FreeTacMan 是触觉传感系统而不是完整的手，因为它们通常配合灵巧操作使用而放在本类，并在数据文件中标注了类型。Dextra 是更早期的 Hackaday 设计，不少字段仍为「未知」。
