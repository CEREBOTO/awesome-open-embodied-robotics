## Comparison

This is the largest category in the first batch. Low-cost 3D-printed tendon or hybrid hands (LEAP Hand v2, whose official parts page now says parts cost around USD 300 because of tariffs, and still prints an August 2025 split of USD 221.95 Feetech + USD 251.53 other; Robot Nano Hand; DexHand) sit beside Dynamixel-based research hands (LEAP Hand v1, RUKA, ORCA, LEAP Hand v2 Advanced). Licenses are not uniform: the LEAP Hand v1 CAD request page states CC BY-SA 4.0 (commercial use with attribution and share-alike), while the v1 API is CC BY-NC 4.0 and LEAP Hand v2 states CC BY-NC-SA for CAD. ORCA hardware is CC BY 4.0 (including commercial use with attribution) and RUKA's repo is MIT. eFlesh, FreeTacMan, and OpenTac are tactile sensing systems rather than complete hands; they are kept here because they are usually used with dexterous manipulation, with their type marked in the data file. OpenTac is a flex-PCB tactile-skin toolchain for normal and shear force, with reusable USB readout boards (60-pin up to 30×30 taxels; stacked 30-pin pair up to 15×15). Hardware designs are CERN-OHL-P-2.0 and code is MIT. No official kit price was stated. Dextra is a much older Hackaday-era design; several fields remain Unknown.
