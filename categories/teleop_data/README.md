## Comparison

GELLO, JoyLo, and OpenHomie are leader-side or isomorphic teleoperation systems, mostly Dynamixel-based, for collecting manipulation data. GELLO publishes both software and mechanical repositories under MIT. OpenHomie's LICENSE file is CC BY-NC 4.0, while its README states CC BY-NC-SA 4.0 — both are recorded. DOGlove is a haptic force-feedback glove (official materials: 5 DoF, Dynamixel, MIT-licensed repo; the source site listed CNY-like 4500, which was not used). DexUMI uses the human hand as the manipulation interface for dexterous data collection (MIT-licensed software). ViA (Vision in Action) was listed as a wheeled robot on the source site, but official materials describe an active-perception stack whose public hardware focus is a robotic neck, used with ARX arms and ROS; it is placed here as data-collection / active-perception hardware, not as a mobile manipulator.
