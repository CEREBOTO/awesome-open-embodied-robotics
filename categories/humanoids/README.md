## Comparison

All four are presented as open humanoid platforms, but they differ in cost band, license, and completeness. Berkeley Humanoid Lite emphasizes a sub-USD 5,000, largely 3D-printed build with MIT-licensed code and CC BY-SA 4.0 assets, plus Isaac Lab support. ToddlerBot is a smaller loco-manipulation research humanoid (30 active DoF in official materials) with MIT-licensed code and a non-commercial CC BY-NC-SA design license; the project paper states a build cost under USD 6,000. Poppy Humanoid is the oldest educational/research platform here (25 Dynamixel actuators, official BOM about USD 8,000–9,000) and uses CC BY-SA 4.0 hardware with GPL-3.0 software; the main CAD repo has not been committed to since 2021. Fourier N1 is a 23-DoF, 1.3 m / 38 kg industrial-origin open release with official hardware downloads, but the hardware license was not located, and the public GitHub side is documentation and SDK-related repositories rather than a single monorepo.
